# Sales Performance Dashboard – Excel

## Project Overview
This project is an **interactive Sales Performance Dashboard created in Microsoft Excel** to analyze sales performance across different cities, sales executives, target achievement, and distance from target.

The dashboard converts raw sales data into a clear visual report that can be used to understand individual sales performance and compare key KPIs.

## Dashboard Preview
The dashboard contains interactive city selectors and multiple charts/tables for sales analysis.

### Cities Included
- Chennai
- Delhi
- Mumbai
- Nagpur
- Patna
- Pune
- Ranchi
- Surat

## Key Analysis Performed

### 1. Total Sales by Sales Executive
The dashboard displays total sales for selected sales executives and compares their sales performance.

### 2. Target Hit %
A target achievement section shows the percentage of target achieved by each sales executive.

### 3. Away From Target %
The dashboard calculates and displays how far each sales executive is from the assigned target.

### 4. Interactive City Selection
Checkbox controls are used to select a dashboard/city view. The dashboard updates the displayed information based on the selected view.

### 5. Visual Charts
Three main visualizations were created:
- **Total Sales Bar Chart** – compares sales across executives.
- **Target Hit % Bar Chart** – compares target achievement percentages.
- **Away From Target % Line Chart** – shows the percentage away from target for each executive.

## Dashboard KPIs / Example Results
For the displayed dashboard view:
- Total sales shown for the selected sales executives: **1,919**
- Target Hit % values range from approximately **75.80% to 77.80%**
- Away From Target % values range from approximately **65.80% to 71.40%**

> These values represent the dashboard view shown in the project screenshot and may change when a different city/dashboard selection is used.
